# ♞ Шахматные дебюты

Веб-приложение, где шахматные дебюты учатся в игровой форме. Открывается в браузере на ноутбуке и устанавливается на iPhone как отдельное приложение (PWA).

- **21 дебют, 26 вариантов**: за белых, за чёрных и ловушки. У каждого указана популярность (★) и сложность (●), список можно сортировать.
- **Изучение**: сначала экран «Идея дебюта» — позиция, к которой придём, со стрелками. Потом ходишь сам по зелёной стрелке (нужная фигура мигает), ходы соперника появляются по кнопке. Перед каждым твоим ходом — «Зачем этот ход» и «🤔 Почему не по-другому?»: соблазнительные альтернативы с оценкой и предпросмотром «что будет на доске». Неверный ход приложение объясняет. После каждого хода — объяснение, зачем он сделан, и стрелки:
  🟩 наша идея · 🟥 угроза соперника · 🟦 план/защита · 🟨 важное поле.
  Бледно-красные стрелки рисуются автоматически и показывают, какие твои фигуры соперник может выгодно взять.
- **«А что если…»**: побочные варианты и ловушки показывают, к чему приводит другой ход.
- **«👁 Куда может пойти соперник»**: стрелки всех ходов соперника, красные — взятия, отметки фигур под ударом. Нажатие на фигуру соперника показывает только её ходы. Названия клеток в текстах нажимаются и подсвечиваются на доске.
- **Тренировка по памяти**: играешь вариант сам. После ошибки сначала подсвечивается фигура, которой нужно ходить, после второй — показывается стрелка.
- **Интервальные повторения** (система Лейтнера: 1 → 3 → 7 → 14 → 30 → 60 дней). Приложение само напоминает, что пора повторить.
- **Теория**: правила, нотация, 10 правил дебюта, словарь терминов. У каждого дебюта есть раскрывающийся разбор: что значит название, в чём суть, планы, ошибки, интересный факт. Термины в объяснениях («связка», «вилка», «темп»…) можно нажать — появится пояснение.
- **♟ Свободная игра**: играешь как хочешь, а приложение пишет в шапке, какой дебют получается (и когда партия ушла из теории), и оценивает каждый ход: значок прямо на доске (★ по теории, ! хорошо, ?! сомнительно, ? ошибка, ?? грубая ошибка), цветная плашка, вспышка доски, а при ошибке — красная стрелка, как соперник её накажет. Показывает, насколько популярен сделанный ход («так играют в 37% партий»), и очки — стоимость фигур (пешка 1, конь и слон 3, ладья 5, ферзь 9). На ходу соперника — его самые популярные ответы с процентами, стрелками (чем толще, тем чаще) и короткой причиной «зачем этот ход»; выбираешь, как он ответит, или жмёшь «🎲». На телефоне под доской три страницы, которые листаются свайпом: «Разбор», «Ответ соперника / Что играть», «Партия».
- **Игровые элементы**: опыт и уровни (от «Новичка» до «Чемпиона мира»), серия дней 🔥, цель дня, достижения, викторина «Угадай дебют / Найди ход».
- **Lichess**: статистика «что здесь чаще всего играют» из Opening Explorer, кнопки «Анализ» и «Игра с компьютером» с позиции дебюта.
- **🏆 Лучшие ходы**: в свободной игре список ходов переключается между «🔥 Популярные» и «🏆 Лучшие». У каждого хода — «% очков» (как часто так сыгравшие выигрывали) и оценка встроенного движка Stockfish 17.1 («+0.3 у белых · лучший ход / почти так же хорош / чуть хуже / заметно хуже»); в разборе своего хода видно, что думал движок и какой ход был лучше. Движок (~7 МБ) работает прямо в браузере и скачивается один раз — при первом выборе «Лучшие».
- **Встроенные проценты популярности**: если статистика Lichess недоступна (нет токена или интернета), проценты берутся из встроенной статистики — 20 тысяч настоящих партий с Lichess, первые 16 полуходов (`public/data/popularity.json`).
- **Профили**: занимаются двое (например, муж и жена) — у каждого свой прогресс.
- **Синхронизация** телефона и ноутбука без своего сервера — через приватный гист GitHub (подключение телефона по QR-коду), или через свой сервер по секретной фразе.
- Работает офлайн, тёмная и светлая тема.

## Как запустить

### Вариант 1. Свой сервер (рекомендуется: синхронизация + Lichess-прокси)

Нужен Node.js 18+ (зависимостей нет):

```bash
git clone https://github.com/Nelegali/chess.git
cd chess
PORT=8080 node server.js
```

Или через Docker:

```bash
docker compose up -d --build
```

Прогресс для синхронизации хранится в папке `data/` (в Docker — в томе `chess-data`). На диске лежит только хэш секретной фразы.

**HTTPS обязателен для iPhone**: без него Safari не включит офлайн-режим. Пример для nginx + Let's Encrypt:

```nginx
server {
    server_name chess.example.ru;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }
}
```

Затем выполните `sudo certbot --nginx -d chess.example.ru`.

Переменные окружения:

| Переменная      | Значение по умолчанию | Зачем                                                              |
| --------------- | --------------------- | ------------------------------------------------------------------ |
| `PORT`          | `8080`                | порт                                                               |
| `HOST`          | `0.0.0.0`             | адрес                                                              |
| `DATA_DIR`      | `./data`              | где хранить синхронизированный прогресс                            |
| `LICHESS_TOKEN` | —                     | токен Lichess, если Opening Explorer требует авторизацию           |

### Вариант 2. GitHub Pages (бесплатно, без сервера)

1. Один раз: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Workflow `.github/workflows/pages.yml` публикует папку `public/` после каждого push в основную ветку репозитория (запустить вручную: Actions → Pages → Run workflow).
3. Адрес: `https://nelegali.github.io/chess/`.

На GitHub Pages нет синхронизации между устройствами: прогресс хранится в браузере. Перенести его можно через Профиль → «Резервная копия». Для приватного репозитория GitHub Pages доступен только на платном тарифе.

### Установка на iPhone

Откройте адрес в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**. Приложение откроется во весь экран, с иконкой, и будет работать без интернета.

### Профили (несколько человек)

Профиль → «Кто занимается»: два профиля, у каждого свой прогресс, серия, повторения и партия в свободной игре. Имя и значок меняются там же; текущий профиль виден в шапке.

### Синхронизация телефона и ноутбука

**Без своего сервера (подходит для GitHub Pages)** — через приватный гист GitHub:

1. Профиль → «☁️ Синхронизация» → «Создай токен GitHub» (откроется GitHub с уже отмеченным правом `gist`; срок — «No expiration») → вставьте токен → «Подключить».
2. «📱 Подключить телефон» → наведите камеру телефона на QR-код нужного человека (или отправьте себе ссылку и откройте её на телефоне). Телефон подключится и сразу откроется с этим профилем.

Прогресс всех профилей хранится в одном приватном гисте `chess-openings-progress.json`; устройства обмениваются им при открытии приложения и через пару секунд после занятия, копии объединяются (по каждому варианту берётся более свежая). Ссылку и токен никому не пересылайте: по ним можно читать и менять ваши гисты.

**Через свой сервер** — Профиль → «Или через свой сервер» → одинаковая секретная фраза (от 8 символов) на всех устройствах.

## Как добавить свой дебют

Все дебюты лежат в `public/js/openings.js`, теория к ним — в `public/js/theory.js`. Формат шага:

```js
{ m: 'Nf3', t: 'Объяснение хода', a: 'gf3e5 ye5', alt: [/* «а что если…» */] }
```

`a` — стрелки в позиции после хода: первая буква — цвет (`g` зелёный, `r` красный, `b` синий, `y` жёлтый), дальше одно поле (кружок) или два поля (стрелка).

После правок запустите проверки (легальность всех ходов, ручных пояснений, совпадение версий и логика повторений):

```bash
npm test
```

### Как выпустить новую версию

Поменяйте номер версии в трёх местах: `public/js/version.js`, `public/version.json` и `VERSION` в `public/sw.js`. Тест (`npm test`) проверяет, что номера совпадают. Установленные приложения сами заметят новый номер в `version.json`, покажут плашку «Доступна новая версия» и обновятся. Текущая версия видна внизу главной страницы и в Профиле.

## Структура

```
server.js              сервер: статика, /api/progress (синхронизация), /api/explorer (прокси Lichess)
public/index.html      оболочка приложения
public/js/app.js       экраны: главная, дебют, изучение, тренировка, повторение, теория, викторина, свободная игра, профиль
public/js/openings.js  база дебютов
public/js/theory.js    теория, словарь, разбор дебютов
public/js/store.js     прогресс, повторения, опыт, достижения, синхронизация
public/js/board.js     доска (chessground) + правила (chess.js) + стрелки угроз
public/js/popularity.js проценты популярности: Lichess, а без него — встроенная статистика
public/data/popularity.json встроенная статистика ходов (собирается tools/build-popularity.mjs)
public/sw.js           офлайн-режим
tools/                 сборка встроенной статистики из набора партий
tests/                 проверка базы дебютов, статистики и логики прогресса
```
